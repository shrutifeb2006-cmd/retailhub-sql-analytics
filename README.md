## 📌 Overview

**retailHub** is a relational database project built using MySQL to simulate a real-world retail business.

It focuses on:
- Database design (ER modeling)
- SQL-based analytics
- Business insights (sales, customers, inventory)

---

## 🎯 Problem

Retail businesses need to track:
- Sales performance  
- Customer behavior  
- Inventory levels  
- Payments & revenue  

This system organizes data and enables efficient analysis using SQL.
